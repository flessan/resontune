Game ini saat ini dalam versi beta jadi harapkan banyak bug dan perubahan

KONTROL
Ini adalah permainan ritme bentuk bebas, SEMUA jenis input diperlakukan sebagai pukulan!
[apa yang penting adalah seberapa baik waktu Anda]

HOLDNada tahan: tekan tepat di kepala nada, lalu TAHAN sampai ekor nada melewati garis timing. Lepas terlalu cepat = DROP, tahan sampai habis = CLEAR + bonus skor. Cincin di sekitar receptor menunjukkan sisa durasi tahanan.

🎵 Semua musik dalam game ini diperoleh dengan benar dengan mendapatkan izin dari artis
(musik berasal dari file lokal milikmu sendiri dan tidak pernah diunggah ke mana pun)

Terinspirasi dari TONS game ritme tetapi terutama: Unbeatable / Muse Dash (Layout), Rhythm Heaven / Rhythm Doctor / Phigros (Gimmicks), Arcaea / Chunithm (Sistem Penilaian), DDR (Note quantization)

FITUR
• Kesulitan Easy / Normal / Hard — kecepatan, jendela timing, dan pengali skor berbeda
• Nyawa: meleset mengurangi nyawa, game over di 0
• Jeda (Esc / keluar aplikasi), hitung mundur 3-2-1, layar hasil dengan grade SS–F
• High score tersimpan per kesulitan di perangkat
• Kalibrasi offset audio & volume, getaran haptic, layar tetap menyala saat bermain
• Bisa di-install seperti aplikasi native (tombol Install di bilah atas)
