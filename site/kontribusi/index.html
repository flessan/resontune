Cara Berkontribusi

Site ini open source dan kami sangat mengapresiasi kontribusi dari siapa saja. Berikut panduan lengkapnya.

Tentang Project Ini

Rubik Indonesia adalah project open source yang bertujuan menyediakan resource belajar rubik 3x3 yang gratis dan mudah diakses untuk komunitas Indonesia. Site ini baru saja dimulai dan masih dalam pengembangan awal.

Kami percaya bahwa belajar rubik seharusnya bisa diakses oleh siapa saja, tanpa biaya. Semua konten di site ini gratis dan akan tetap gratis selamanya.

Repository GitHub: github.com/flessan/Rubik

Cara Berkontribusi (Developer)

Jika kamu seorang developer dan ingin berkontribusi dalam pengembangan site ini, berikut langkah-langkahnya:

1
Fork Repository
Klik tombol "Fork" di repository GitHub untuk membuat copy di akun kamu.
2
Clone Repository
Clone repository yang sudah di-fork ke komputer lokal kamu.
git clone https://github.com/username-kamu/Rubik.git
3
Buat Branch Baru
Buat branch baru untuk fitur atau perbaikan yang ingin kamu kerjakan.
git checkout -b fitur-baru-kamu
4
Lakukan Perubahan
Edit file, tambahkan fitur, atau perbaiki bug sesuai kebutuhan.
5
Commit & Push
Commit perubahan kamu dan push ke repository fork kamu.
git add .
git commit -m "Tambah fitur baru"
git push origin fitur-baru-kamu
6
Buat Pull Request
Buka pull request dari branch kamu ke repository utama. Jelaskan perubahan yang kamu lakukan.

Cara Berkontribusi (Non-Developer)

Tidak harus jadi developer untuk berkontribusi! Kamu juga bisa membantu dengan cara:

Lapor Bug
Jika menemukan bug atau error di site, laporkan di GitHub Issues. Sertakan screenshot dan deskripsi masalah.
Saran & Feedback
Punya ide fitur baru atau saran perbaikan? Buka issue di GitHub dan diskusikan dengan kami.
Perbaikan Konten
Jika menemukan typo, kesalahan penjelasan, atau konten yang kurang jelas, silakan laporkan atau perbaiki.
Share ke Teman
Bantu sebarkan site ini ke teman-teman kamu yang ingin belajar rubik. Semakin banyak yang tahu, semakin baik!
Kontribusi Gambar
Punya gambar tutorial rubik yang bagus? Kirimkan ke kami untuk ditambahkan ke site.
Terjemahan
Bantu terjemahkan konten ke bahasa daerah atau bahasa lainnya untuk menjangkau lebih banyak orang.

Panduan Kontribusi

Beberapa hal yang perlu diperhatikan saat berkontribusi:

✓
Ikuti Style Code yang Ada
Usahakan mengikuti style code yang sudah ada di project untuk konsistensi.
✓
Test Sebelum Submit
Pastikan perubahan kamu sudah ditest dan tidak menimbulkan bug baru.
✓
Deskripsi yang Jelas
Saat membuat pull request atau issue, berikan deskripsi yang jelas dan detail.
✓
Hormati Kontributor Lain
Selalu bersikap sopan dan menghormati kontributor lainnya dalam diskusi.

Siap Berkontribusi?

Setiap kontribusi, sekecil apapun, sangat berarti untuk project ini. Mari kita bangun resource belajar rubik terbaik untuk Indonesia!
